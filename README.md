# Open Library Books

اسکریپت پایتون برای دریافت اطلاعات کتاب‌ها از API عمومی Open Library، فیلتر کردن کتاب‌هایی که بعد از سال ۲۰۰۰ منتشر شده‌اند و ذخیره خروجی در فایل CSV.

## ویژگی‌ها

- دریافت کتاب از Open Library API
- فیلتر کتاب‌های منتشر شده بعد از سال ۲۰۰۰
- مرتب‌سازی بر اساس سال انتشار
- ذخیره ۵۰ کتاب در فایل CSV

## نحوه اجرا

```bash
pip install -r requirements.txt
python main.py
```
